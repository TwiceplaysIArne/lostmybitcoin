Lost My Bitcoin Poster

Lost My Bitcoin Poster is a small tool made by the developer of the video game Lost My Bitcoin. It publishes the game's own news, pictures and videos to the game's own accounts on Discord, Reddit, Instagram and TikTok. It is used only by the developer and is not offered to anyone else.

What the tool accesses

Only the game's own accounts, and only after the developer has authorized it on each platform:

  • TikTok: user.info.basic, which TikTok requires for signing in; the tool keeps only the account's open ID (open_id) to know which account it is connected to and never fetches the name, avatar or other profile data. video.upload, to send the game's own videos to the account's TikTok inbox as drafts, which the developer then finishes and posts in the TikTok app. Sign-in uses TikTok's official login with PKCE and a callback on the developer's own computer (localhost).
  • Instagram and Facebook: the game's Facebook page and the Instagram account linked to it (Meta permissions instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement, business_management), to publish the game's own videos as Reels. Instagram fetches each video from the game's Discord post.
  • Discord and Reddit: the game's own server and subreddit, to post news and keep their setup (channels, roles, rules, flairs, wiki pages) up to date. To do this the tool briefly looks at the server's settings, for example whether a starter channel is still empty, and keeps none of it.

What the tool stores

  • Access and refresh tokens, the app keys and the IDs of the connected accounts and pages, kept only on the developer's own computer and never shared.
  • The IDs and links of the posts it published, so nothing is posted twice. These contain no data about other people and are kept in the game's private project files and, for Reddit, in the Reddit app's own storage on Reddit.

What the tool does not do

It does not collect, sell or share any data about other people. It does not read private messages, does not track anyone and does not show ads.

Deleting data

Access can be revoked at any time in the settings of each platform. The developer deletes the stored tokens when access is revoked or the tool is no longer used.

This website

This website is a static page hosted by GitHub Pages. It sets no cookies, loads nothing from other hosts and has no tracking.
