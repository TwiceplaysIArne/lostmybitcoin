# Lost My Bitcoin – website

This is the small static website of **Lost My Bitcoin**, a first-person search and tycoon game in development for PC: 12,000 trash bags, one hard drive, 100 Bitcoin. The pages (plain HTML and one CSS file, no cookies, no tracking, nothing loaded from other hosts) are generated from the game's private project and published here with GitHub Pages at https://twiceplaysiarne.github.io/lostmybitcoin/. Questions, feedback and playtests: join the Discord at https://discord.gg/CkHR3QNAt3.
